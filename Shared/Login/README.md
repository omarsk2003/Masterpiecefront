# Login preview

صفحة دخول واحدة، بتصميم غامق ثابت وبدون تبديل مظهر.

الحسابات التالية وهمية للتجربة فقط، وكلها بكلمة مرور `Lift2026!`:

| الدور | البريد |
| --- | --- |
| العميل | client@lift.demo |
| العميل — Free Plan | client.free@lift.demo |
| العميل — AI Plan | client.ai@lift.demo |
| الكوتش | coach@lift.demo |
| أخصائي التغذية | nutritionist@lift.demo |
| الأدمن | admin@lift.demo |

الحسابات التجريبية أعلاه ثابتة داخل login.js. دخول العميل يحفظ الخطة المختارة محليًا حتى تظهر واجهة Free أو AI أو Premium المناسبة، وتُمسح حالة الدخول عند تسجيل الخروج. حسابات العملاء المسجلة من الواجهة تُحفظ محليًا على نفس المتصفح مع بصمة مملّحة لكلمة المرور، ويمكن تسجيل الدخول إليها بعد الخروج. هذه المحاكاة لا تحمي الصفحات؛ يجب استبدالها بمصادقة من الباك إند لاحقًا.

طلبات تسجيل الكوتش وأخصائية التغذية الجديدة تُحفظ محليًا على نفس المتصفح والجهاز. يستطيع صاحب الطلب تسجيل الدخول بعد اعتماد الأدمن فقط؛ أما Pending فيظهر له تنبيه انتظار المراجعة. تُحفظ بصمة مملّحة لكلمة المرور بدل النص نفسه في IndexedDB، لكن هذا يبقى سلوك معاينة ولا يحمي الصفحات مثل مصادقة الخادم.

نسيان كلمة المرور يفتح توضيحًا أن الخدمة لم تربط بعد؛ لا يرسل بريدًا وهميًا ولا يدعي نجاح إعادة التعيين.
