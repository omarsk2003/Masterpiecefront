# الأجزاء المشتركة

الأجزاء المشتركة مقسمة حسب الواجهة: Client وAdmin وCoach وNutrition وPublic.

لكل واجهة Navbar وSidebar وFooter، باستثناء Public الذي يحتوي Navbar وFooter فقط. كل جزء داخل مجلد مستقل فيه HTML وCSS وJS.

مثال: `Shared/Components/Coach/Navbar/navbar.html` مع `navbar.css` و`navbar.js` في نفس المجلد.

ملفات HTML هنا قوالب أجزاء فقط، وليست صفحات كاملة. لا نكرر Navbar مختلفًا داخل كل صفحة؛ نستخدم قالب الدور كمرجع مشترك عند بناء الصفحات. آلية إدراج القوالب لاحقًا تحدد وقت التنفيذ، والهيكل الحالي لا يحمّلها تلقائيًا.

عند إدراج جزء في صفحة مثل `Coach/Dashboard/dashboard.html`، روابطه النسبية تعمل من مكان تلك الصفحة. أضف رابط CSS ووسم script للجزء في الصفحة وقت استخدامه.

لا يوجد تحميل تلقائي لملفات HTML. الصفحات الحالية مستقلة وتعمل بروابط نسبية.
